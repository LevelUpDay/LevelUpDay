# 🧩 LevelUpDay Focusgate — brauzer kengaytmasi (Chrome / Edge / Brave / Opera / Yandex)

- Saytlarni bloklaydi (doimiy, jadval, kunlik limit, fokus) — `blocked.html` sahifasiga yo'naltiradi
- Sayt ichida: YouTube Shorts / tavsiyalar / izohlar, Instagram Reels / Explore, Facebook Reels (`insite.js`, `cfg.inSite`)
- Faol tabdagi saytda o'tgan vaqtni hisoblaydi va har daqiqada `supabase/functions/focusgate` bilan sinxronlanadi
- Ulash: popup → "Akkauntga ulash" → LevelUpDay'da "Ulash"

O'rnatish (Web Store'ga chiqarilgunga qadar): `downloads/focusgate-extension.zip` → oching (fayllar ZIP ildizida — papka ichida papka bo'lmaydi) → `chrome://extensions` → Developer mode → Load unpacked. Rasmli yo'riqnoma saytda: Focusgate → Bloklash → O'rnatish (`downloads/guide/`).
Yangilash: shu papkadagi fayllarni o'zgartirib, `downloads/focusgate-extension.zip` ni qayta yig'ing (fayllar ZIP ildiziga, `focusgate-extension/` prefiksisiz).
